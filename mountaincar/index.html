同じ脳・同じ探索のまま、ドーパミンの流し方だけを変えて、seed（乱数）の違う 5 匹に各 100 試行まで学習させた結果です （Python 版 mountaincar/compare.py で計測）。上のセレクトで同じ条件をここで試せます。
ドーパミン初ゴール習得（10 連続）学習中のゴール学習停止後速度の向きに押した

流さない: 重みの変化は「学習率 × ケニヨン細胞の活動 × ドーパミン」なので、1 つも変わらず、ほぼランダムに押したまま。

報酬と無関係に流す: 量は同じでも報酬と対応していないので、重みがでたらめに動き、押し方が片寄ってランダムより悪くなる。 効いているのはドーパミンの量ではなく、ドーパミンが報酬の情報を運ぶこと。

ゴールしたときだけ: 学習前の脳は一度もゴールに届かないので、ドーパミンが一度も流れず「流さない」と完全に同じになる。 あっという間に覚えたのは、エネルギーの増分という毎ステップ届く報酬のおかげ。

しくみ

見る: 車の状態（位置, 速度）を 12×12 の絵（その点にぼかした丸）にして、嗅覚の投射ニューロン 685 個に入れます。 キノコ体のケニヨン細胞 5,177 個が、状態ごとに違う疎な発火パターンになります。脳全体は嗅覚入力で暴走するため、キノコ体以外は止めています。

選ぶ: MBON 96 個を「左に押す／押さない／右に押す」の 3 区画に分け、80 ms 見せたあと、ケニヨン細胞にいちばん駆動されない区画の行動をとります（探索として初めは 10% ランダム、試行ごとに ×0.97）。

学ぶ: 1 ステップ進めた報酬を、状態を見せたまま、選んだ区画へのドーパミン（±1 で頭打ち）として 60 ms 流します。 正なら発火していたケニヨン細胞→その MBON のシナプスが弱まって次もその行動が選ばれやすく、負なら強まって選ばれにくくなります。 重みの変化は WebAssembly のスパイキングモデルの可塑性ルールの中で起きます。

報酬は下の MountainCarEnergyReward だけ（力学的エネルギーの増分 ×10000、ゴールで +50）。環境は gymnasium の MountainCar-v0（最大 200 ステップ）を JavaScript に移植したもので、 Python 版（mountaincar/train.py）と同じ式です。「ドーパミン」のセレクトで、流し方を変えた対照（流さない／報酬と無関係／ゴール時だけ）に切り替えられます。

使っている報酬関数（Python の原文） 
class MountainCarEnergyReward(gym.Wrapper):
    """位置・運動エネルギーの増分を報酬にするラッパー。"""

    def __init__(self, env, ke_scale=1.0, goal_bonus=50.0):
        super().__init__(env)
        self.prev_energy = None
        self.g = 9.8
        self.ke_scale = ke_scale
        self.goal_bonus = goal_bonus

    def reset(self, **kwargs):
        obs, info = self._unpack_reset(self.env.reset(**kwargs))
        obs = self._ensure_obs_shape(obs)
        self.prev_energy = self.compute_energy(obs)
        return obs, info

    def step(self, action):
        obs, _orig, terminated, truncated, info = self._unpack_step(
            self.env.step(action)
        )
        obs = self._ensure_obs_shape(obs)

        current_energy = self.compute_energy(obs)
        shaped = 10000.0  * (current_energy - self.prev_energy)
        self.prev_energy = current_energy

        if terminated and obs[0] >= self.env.unwrapped.goal_position:
            shaped += self.goal_bonus
            info["reached_goal"] = True

        return obs, shaped, terminated, truncated, info

    def compute_energy(self, obs):
        position, velocity = obs
        kinetic   = 0.5 * velocity ** 2
        potential = (0.0025 / 3.0) * np.sin(3.0 * position)
        return kinetic + potential
