# mountaincar — ハエのキノコ体が Mountain Car を学習する

FlyWire v783 コネクトーム（`../flybrain/`、Shiu et al. 2024 の LIF 全脳モデル）のうちキノコ体だけを動かし、
gymnasium の `MountainCar-v0` を学習させる。報酬は `MountainCarEnergyReward`（力学的エネルギーの増分
×10000、ゴールで +50）のみ。

```sh
py -3.12 -m pip install gymnasium numpy
py -3.12 mountaincar/train.py                      # 10 回連続ゴールまで（最大 300 エピソード）
py -3.12 mountaincar/train.py --eta 0 --streak 999 --episodes 30 --eval 0   # 対照: 学習なし
```

Node 18+ が必要（`brain.mjs` は `--experimental-detect-module` 付きで起動される）。

## ブラウザで見る

サイトの他のページと同じく、リポジトリのルートを静的に配信して `/mountaincar/` を開く:

```sh
npx serve . -l 3033        # → http://localhost:3033/mountaincar/
```

脳（`worker.js`）も学習もブラウザの中で動く。車の動き、試行ごとのステップ数、初成功・習得（10 回連続ゴール）の試行番号、
脳が覚えた押し方（位置×速度ごとの行動）、MBON 区画の駆動が見られる。「ドーパミン」のセレクトで、下の比較と同じ
4 条件（報酬どおり / 流さない / 報酬と無関係 / ゴール時だけ）に切り替えられ、そのステップに流したドーパミンの量も出る。
`compare.json`（`compare.py` の結果）があれば、比較実験の表と条件別の学習曲線もページに載る。
環境と報酬は `app.js` に gymnasium の `MountainCar-v0`（float32 の状態、200 ステップ打ち切り）と
`MountainCarEnergyReward` を 1 行ずつ移したもの。

## 仕組み

- `train.py` — 環境・報酬ラッパー・学習ループ・記録（`--dopa` でドーパミンの条件を切り替え）。
- `compare.py` — ドーパミンの条件 × seed をまとめて走らせて結果を並べる。
- `index.html` / `app.js` / `worker.js` — ブラウザ版（環境・報酬・描画 / 脳）。
- `brain.mjs` — Python から使う脳（Node 子プロセス、JSON 行で通信）。
- `fly.mjs` — 両方が使う脳の本体。`juku/reader.mjs` と同じ作り:
  - 状態 (位置, 速度) を 12×12 の絵（その点にぼかした丸）にし、各画素が投射ニューロン 685 個の一部を駆動 →
    ケニヨン細胞 5,177 個の疎なコード。
  - MBON 96 個を 3 つの区画（左に押す / 押さない / 右に押す）に分け、ケニヨン細胞からの駆動が最も弱い区画を行動にする。
  - 1 ステップ進めて得た報酬を、状態を見せたまま選んだ区画へのドーパミンにする（±1 で頭打ち）。
    正 → その区画の活動 KC→MBON シナプスが弱まり、この状態でその行動が選ばれやすく。負 → 強まり選ばれにくく。
  - 探索は ε-greedy（初期 0.1、エピソードごとに ×0.97）。

## 何回で成功したか

1 行ごとにエピソードの結果、最後に:

- **初成功** — 初めてゴールした試行（エピソード）番号と、それまでの累計ステップ数
- **習得** — `--streak` 回（既定 10）連続でゴールした試行番号
- **学習停止後テスト** — 学習も探索も止めて 20 回走らせたときのゴール数

記録は `runs/<日時>-seed<n>-eta<η>/` の `episodes.csv`（エピソードごと）と `summary.json`。

2026-09-23 の結果（既定設定）:

| | 初成功 | 習得（10 連続） | 学習停止後 |
|---|---|---|---|
| seed 1 | 1 回目（170 ステップ） | 10 回目（累計 1,365 ステップ） | 20/20（平均 120.8 ステップ） |
| seed 2 | 1 回目（131 ステップ） | 10 回目（累計 1,459 ステップ） | 20/20（平均 123.1 ステップ） |
| seed 3 | 1 回目（169 ステップ） | 10 回目（累計 1,575 ステップ） | 20/20（平均 125.0 ステップ） |
| 対照 η=0 | 30 回で 0 回 | — | — |

報酬が毎ステップ届く（速度の向きに押せば正、逆なら負）ため、最初のエピソードの中で「速度の向きに押す」を覚えて
ゴールまで行く。対照（可塑性なし）は同じ脳・同じ探索で一度もゴールせず、最高位置は −0.4 前後、速度の向きに押す割合は約 30%。

## ドーパミンの条件を変えた比較

学習があっという間なので、ドーパミンの何が効いているのかを条件を変えて確かめた。`train.py --dopa` で切り替える:

| `--dopa` | 脳に返すもの |
|---|---|
| `reward`（既定） | 報酬をそのままドーパミンに |
| `none` | ドーパミンなし（可塑性はオンのまま、ドーパミンを一切流さない） |
| `shuffle` | ドーパミンはあるが報酬と無関係（毎ステップ報酬の符号をランダムに反転。量と大きさの分布は同じ） |
| `goal` | ゴールしたときだけドーパミン（エネルギーの増分は使わない＝疎な報酬） |

```sh
py -3.12 mountaincar/compare.py            # 4 条件 × seed 1-5、各 100 エピソードまで、同時 3 本
py -3.12 mountaincar/compare.py --out mountaincar/runs/compare-<日時>   # 止まったところから
```

記録は `runs/compare-<日時>/` に各 run と `results.csv`・`summary.md`・`compare.json`（matplotlib があれば学習曲線の `compare.png`）。
`compare.json` を `mountaincar/` にコピーすると、ブラウザ版に表と学習曲線が出る（いま置いてあるのは下の結果）。
脳を同時に読み込みすぎるとメモリ不足で落ちることがあるので、失敗した run は待ってからやり直す。

2026-09-23 の結果（seed 1–5、各 100 エピソードまで、学習停止後テストは各 20 回）:

| 条件 | 初成功 | 習得（10 連続） | 学習中のゴール | 学習停止後 | 速度の向きに押した | 最高位置（平均） |
|---|---|---|---|---|---|---|
| 報酬→ドーパミン | 5/5 seed（全て 1 回目） | 5/5 seed（中央値 10 回目） | 57/58 | 100/100 | 86% | +0.53 |
| ドーパミンなし | 0/5 | 0/5 | 0/500 | 0/100 | 34% | −0.21 |
| 無関係なドーパミン | 0/5 | 0/5 | 0/500 | 0/100 | 17% | −0.23 |
| ゴール時のみ | 0/5 | 0/5 | 0/500 | 0/100 | 34% | −0.21 |

- **ドーパミンなし** — 可塑性の規則は「学習率 × ケニヨン細胞の活動痕跡 × ドーパミン」なので、ドーパミンがなければ重みは
  1 つも動かず、η=0 の対照と同じになる。行動は未学習の脳のまま（3 区画の駆動が等しく、ほぼランダム）で、速度の向きに押すのは
  偶然の約 1/3。500 エピソードで一度もゴールしない。
- **無関係なドーパミン** — ドーパミンの量は本来の条件と同じでも、報酬と対応していなければ学習にならない。重みは報酬と無関係に
  ランダムウォークし、多くの seed で「押さない」か片側への押し方に偏っていく（例: seed 4 は 100 回目で 左/無/右 = 1/186/13）。
  そのため速度の向きに押す割合はランダム（34%）より悪い 17%。可塑性があること・ドーパミンが流れることではなく、
  **ドーパミンが報酬の情報を運ぶこと**が学習の決め手。
- **ゴール時のみ** — 未学習の脳は一度もゴールに届かないので、ドーパミンは一度も流れず、結果は全 seed でドーパミンなしと完全に一致する。
  つまり「あっという間」に覚えたのは、エネルギーの増分という**毎ステップ届く報酬**のおかげ。
  ゴールの報酬だけではこの脳と探索（ε-greedy、初期 0.1）では学習の糸口すらつかめない。
