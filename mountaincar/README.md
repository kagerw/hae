# mountaincar — ハエのキノコ体が Mountain Car を学習する

FlyWire v783 コネクトーム（`../flybrain/`、Shiu et al. 2024 の LIF 全脳モデル）のうちキノコ体だけを動かし、
gymnasium の `MountainCar-v0` を学習させる。報酬は `MountainCarEnergyReward`（力学的エネルギーの増分
×10000、ゴールで +50）のみ。

```sh
py -3.12 -m pip install gymnasium numpy
py -3.12 mountaincar/train.py                      # 10 回連続ゴールまで（最大 300 エピソード）
py -3.12 mountaincar/train.py --eta 0 --streak 999 --episodes 30 --eval 0   # 対照: 学習なし
```

Node 18+ が必要（`brain.mjs` は `--experimental-detect-module` 付きで起動される）。

## ブラウザで見る

サイトの他のページと同じく、リポジトリのルートを静的に配信して `/mountaincar/` を開く:

```sh
npx serve . -l 3033        # → http://localhost:3033/mountaincar/
```

脳（`worker.js`）も学習もブラウザの中で動く。車の動き、試行ごとのステップ数、初成功・習得（10 回連続ゴール）の試行番号、
脳が覚えた押し方（位置×速度ごとの行動）、MBON 区画の駆動が見られる。「学習する」を外すと可塑性なしの対照になる。
環境と報酬は `app.js` に gymnasium の `MountainCar-v0`（float32 の状態、200 ステップ打ち切り）と
`MountainCarEnergyReward` を 1 行ずつ移したもの。

## 仕組み

- `train.py` — 環境・報酬ラッパー・学習ループ・記録。
- `index.html` / `app.js` / `worker.js` — ブラウザ版（環境・報酬・描画 / 脳）。
- `brain.mjs` — Python から使う脳（Node 子プロセス、JSON 行で通信）。
- `fly.mjs` — 両方が使う脳の本体。`juku/reader.mjs` と同じ作り:
  - 状態 (位置, 速度) を 12×12 の絵（その点にぼかした丸）にし、各画素が投射ニューロン 685 個の一部を駆動 →
    ケニヨン細胞 5,177 個の疎なコード。
  - MBON 96 個を 3 つの区画（左に押す / 押さない / 右に押す）に分け、ケニヨン細胞からの駆動が最も弱い区画を行動にする。
  - 1 ステップ進めて得た報酬を、状態を見せたまま選んだ区画へのドーパミンにする（±1 で頭打ち）。
    正 → その区画の活動 KC→MBON シナプスが弱まり、この状態でその行動が選ばれやすく。負 → 強まり選ばれにくく。
  - 探索は ε-greedy（初期 0.1、エピソードごとに ×0.97）。

## 何回で成功したか

1 行ごとにエピソードの結果、最後に:

- **初成功** — 初めてゴールした試行（エピソード）番号と、それまでの累計ステップ数
- **習得** — `--streak` 回（既定 10）連続でゴールした試行番号
- **学習停止後テスト** — 学習も探索も止めて 20 回走らせたときのゴール数

記録は `runs/<日時>-seed<n>-eta<η>/` の `episodes.csv`（エピソードごと）と `summary.json`。

2026-09-23 の結果（既定設定）:

| | 初成功 | 習得（10 連続） | 学習停止後 |
|---|---|---|---|
| seed 1 | 1 回目（170 ステップ） | 10 回目（累計 1,365 ステップ） | 20/20（平均 120.8 ステップ） |
| seed 2 | 1 回目（131 ステップ） | 10 回目（累計 1,459 ステップ） | 20/20（平均 123.1 ステップ） |
| seed 3 | 1 回目（169 ステップ） | 10 回目（累計 1,575 ステップ） | 20/20（平均 125.0 ステップ） |
| 対照 η=0 | 30 回で 0 回 | — | — |

報酬が毎ステップ届く（速度の向きに押せば正、逆なら負）ため、最初のエピソードの中で「速度の向きに押す」を覚えて
ゴールまで行く。対照（可塑性なし）は同じ脳・同じ探索で一度もゴールせず、最高位置は −0.4 前後、速度の向きに押す割合は約 30%。
