# sanmoku — ハエのキノコ体と三目並べ

FlyWire v783 コネクトーム（`../flybrain/`、Shiu et al. 2024 の LIF 全脳モデル）のうちキノコ体だけを動かし、
三目並べ（○×ゲーム）を打たせる。ハエが ○、相手が ×。勝ち負けから自分で学ぶか、1 手ごとに先生（ミニマックス）に直されて学ぶ。

## ブラウザで遊ぶ

サイトの他のページと同じく、リポジトリのルートを静的に配信して `/sanmoku/` を開く:

```sh
npx serve . -l 3034        # → http://localhost:3034/sanmoku/
```

脳（`worker.js`）も学習もブラウザの中で動く。

- **相手**: あなた（盤をクリック）/ でたらめに打つ相手 / 負けない相手（ミニマックス）。あなた以外なら「▶ 続けて対戦」で自動で打ち続ける。
- **学び方**: 自分で学ぶ（勝ち負けから）/ 先生に教わる（1 手ごと）/ 学ばない。
- **探索**: 学んでいるあいだ、ときどきでたらめに打つ（はじめ 10%、学んだ対戦 1 局ごとに ×0.995）。
- 盤の右に、ハエが打ったときの空きマスごとの MBON 区画への駆動（何も学んでいない脳 = 1、いちばん小さいマスに打つ）と、先生の手直しが出る。
- 学んだ重みはブラウザの IndexedDB、対戦の記録は localStorage に残り、開き直しても続きから。「忘れさせる」で脳だけ最初に戻る。
- **レート**: 1 局ごとに Elo（K = 32）でハエのレートを動かし、推移をグラフにする。でたらめな相手を 1000、負けない相手を 1462 に固定
  （負けない相手はでたらめな相手に 4000 局で 3478 勝 522 分 0 敗 = 得点率 93.5% = 462 点差）。何も学んでいないハエはでたらめに打つので 1000 から始め、
  忘れさせると 1000 に戻る。あなたがハエと打つと、あなたのレートも動く。負けない相手には引き分けまでなので、1462 あたりが上限。
  上の「結果」の成績をレートに直すと、先生に教わったハエはどちらの相手から見ても 1200〜1260、自分で学んだハエはでたらめな相手からは約 1290、負けない相手からは約 970。

## 仕組み

- `fly.mjs` — 脳の本体（ページの `worker.js` と `train.mjs` が同じものを使う）。`mountaincar/fly.mjs` と同じ作り:
  - 盤面を 12×12 の絵（1 マス = 4×4 画素）にする。○ は各辺の中ほど 8 画素（輪）、× は四隅と中央 8 画素（十字）で、
    同じマスの ○ と × は 1 画素も重ならない。各画素が投射ニューロン 685 個の一部を駆動 → ケニヨン細胞 5,177 個の疎なコード。
  - MBON 96 個を 9 区画（1 マスに 1 つ）に分け、80 ms 見せたあと、空きマスのうちケニヨン細胞からの駆動が最も弱い区画のマスに打つ。
  - **自分で学ぶ**: 対戦が終わったら、ハエが打った局面をもう一度見せながら、打ったマスの区画に結果をドーパミンとして 60 ms 流す
    （勝ち +1、引き分け +0.3、負け −1。最後の手に全部、1 手さかのぼるごとに ×0.7。`rules.mjs` の `dopamineFor`）。
  - **先生に教わる**: 打つたびに、局面を見せたまま、手がミニマックスの最善手でなければ選んだ区画に −1、最善手の区画に +1。
    よい手のときは何も流さない（ひらがなの塾と同じく、間違えたときだけ）。
  - 正のドーパミンは活動していた KC→MBON シナプスを弱めて（そのマスが選ばれやすく）、負は強める（選ばれにくく）。
    学習率 η = 1e-3（mountaincar の 6e-5 では 1 局に数回しかドーパミンが来ないので、1000 局でも重みがほとんど動かない）。
- `rules.mjs` — 勝ち負けの判定、でたらめ・負けない相手、結果のドーパミン、探索率。ページと `train.mjs` で共通。
- `index.html` / `app.js` / `worker.js` — ブラウザ版（盤・記録 / 脳）。
- `train.mjs` — Node で学習させ、途中で学習と探索を止めてでたらめ・負けない相手と 100 局ずつ打たせて測る。

```sh
node --experimental-detect-module sanmoku/train.mjs games=1000 every=250 test=100 mode=teach
#   mode=self|teach  explore=1|0  eta=  opp=random|perfect|mix  win= draw= loss= decay=  punish= praise=  seed=  out=brain.bin.gz
```

1 局 0.2〜0.3 秒ほど（学習と測定を合わせて 1000 局で約 10 分、並行して走らせるとそのぶん遅くなる）。

## 結果

2026-09-30、seed 1、でたらめな相手と 1000 局学んだあと（先手は交互）、学習と探索を止めて 100 局ずつ打たせた「勝ち / 引き分け / 負け」。
三目並べは負けない相手には勝てないので、そちらは引き分けの数が強さ。

| 条件 | でたらめな相手 | 負けない相手 | 区画の重み |
|---|---|---|---|
| 学ぶ前 | 49 / 16 / 35 | 0 / 12 / 88 | 1.00 |
| 自分で学ぶ | 83 / 2 / 15 | 0 / 11 / 89 | 0.50〜0.91 |
| 自分で学ぶ＋探索 | 72 / 3 / 25 | 0 / 9 / 91 | 0.48〜0.89 |
| 先生に教わる | 80 / 4 / 16 | 0 / **37** / 63 | 0.83〜0.86 |
| 先生に教わる＋探索 | 78 / 5 / 17 | 0 / **30** / 70 | 0.84〜0.86 |

- 自分で学ぶと、でたらめな相手には強くなる（5 割 → 8 割）が、負けない相手の攻めは防げるようにならない。結果が対戦の最後にしか来ず、どの手が悪かったかが伝わりにくい。
- 先生に教わると、負けない相手との引き分けが約 3 倍になる。1000 局で直された手は約 1,000 手。
  重みはどの区画もほぼ同じだけ下がる — 「このマスが好き」ではなく、局面ごとに違うマスを選ぶことを覚えている。
- 学習率は 3e-4 / 1e-3 / 3e-3 で差がなかった（でたらめな相手に 77〜83 勝）。
- 探索を入れてもはっきりした差は出なかった。ポアソン入力で同じ盤面でも毎回駆動が揺れるので、それが探索の代わりになっている。

### 罰は効いているか

1 つの盤面でマス 3 に −1 を 3 回流すと、その盤面でのマス 3 の駆動は 1.000 → 1.206 になり、50 回見せて一度も選ばれなくなる
（+1 なら 0.787 になり 50 回とも選ばれる）。仕組みの上では罰も報酬と同じ大きさで効く。それでも罰だけではあまり学べない:

| 条件（探索なし） | でたらめな相手 | 負けない相手 | 区画の重み |
|---|---|---|---|
| 自分で・報酬と罰 | 83 / 2 / 15 | 0 / 11 / 89 | 0.50〜0.91 |
| 自分で・罰なし（`loss=0`） | 59 / 9 / 32 | 0 / 13 / 87 | 0.41〜0.78 |
| 自分で・罰だけ（`win=0 draw=0`） | 63 / 9 / 28 | 0 / 7 / 93 | 1.39〜1.49 |
| 先生・報酬と罰 | 80 / 4 / 16 | 0 / 37 / 63 | 0.83〜0.86 |
| 先生・罰なし（`punish=0`） | 70 / 12 / 18 | 0 / 29 / 71 | 0.48〜0.58 |
| 先生・罰だけ（`praise=0`） | 71 / 8 / 21 | 0 / 12 / 88 | 1.45〜1.56 |

- ハエはいちばん駆動の弱いマスに打つので、報酬は「ここ」と 1 マスに決めるが、罰は 1 マスを候補から外すだけで、残りはでたらめのまま。
- 似た盤面ではケニヨン細胞の発火も似ているため、あちこちで受けた罰が 9 区画をどれも同じように強め（1.4〜1.5）、区画どうしの差 = どこに打つかの情報が残らない。
- 先生モードでは罰だけにすると、負けない相手との引き分けが学ぶ前と同じ 12 局に戻る。

どれも seed 1 本・100 局の測定なので ±10 局ほどは偶然の範囲。自分で学ぶ場合の条件の差（83 と 59〜63）は seed を増やして確かめたい。
